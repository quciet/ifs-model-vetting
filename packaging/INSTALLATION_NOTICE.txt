Included software

IFs Model Vetting includes its own Python 3.14.8 runtime and NumPy 2.5.3,
along with Tcl/Tk, a PyInstaller bootloader, the .NET 10 runtime, and
Parquet.Net 2.1.4. These components support the local interface, numerical
comparisons, and reading IFs model outputs.

You do not need to install Python or these packages separately. They are
installed inside the app folder and do not change your existing Python
installation or system PATH.

IFs Model Vetting is licensed under the MIT License. Bundled third-party
components retain their own licenses. The app folder includes LICENSE,
THIRD_PARTY_NOTICES.txt, and the licenses folder with their license texts.

The app runs locally. Select an existing IFs installation after starting it.
IFs itself and model run files are not included in this installer.
